# De Voorspellingschecker

Publieke site van [@voorspellingchk](https://x.com/voorspellingchk): voorspellingen van bekende Nederlanders en instituten, en of ze zijn uitgekomen.

- `index.html` – de site (statisch, geen server nodig)
- `data.json` – alle voorspellingen en checks; wordt wekelijks bijgewerkt

Voorspelling gezien? Stuur een tip via de knop op de site.
